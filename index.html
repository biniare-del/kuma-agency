제작에 포함되는 것

별도 옵션 없이 기본으로 들어갑니다.

  • 디자인진료과와 병원 분위기에 맞춰 만듭니다.
    PC와 휴대폰 화면을 따로 확인합니다.
  • 페이지 구성시술·진료 안내, 의료진, 오시는 길, 상담 연결까지 기본으로 넣습니다.
  • 검색 기본 설정페이지별 제목과 설명을 넣고, 네이버·구글에 사이트를 등록합니다.
  • AI 검색 대응진료 과목·의료진·위치 정보를 검색엔진과 AI가 읽는 형식으로 정리합니다.
  • 블로그·카톡 연결병원 블로그와 카카오톡 채널을 홈페이지에 연결합니다.
  • 오픈 후 수정문구와 사진 교체를 도와드립니다.

검색 순위와 AI 추천 여부는 각 서비스가 정하며, 결과를 보장하지 않습니다.

진행 순서

자료가 준비되면 시안까지 빠르게 나옵니다.

  1. 카톡 상담진료과와 원하는 분위기를 듣습니다.
  2. 자료 전달병원 소개, 의료진, 사진을 받습니다.
  3. 시안 확인실제 화면으로 보고 고칩니다.
  4. 오픈도메인 연결과 검색 등록까지 마칩니다.
