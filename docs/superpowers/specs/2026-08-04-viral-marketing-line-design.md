# 블로그 바이럴마케팅 사업 라인 추가 — 설계 문서

- **관련 문서**: `CONTEXT.md`(사업 전략), `COLD_EMAIL_TEMPLATES.md`, `professional/index.html`(구조 템플릿)

## 1. 배경 / 목적

꿈을담은에이전시는 현재 **홈페이지 제작(SEO/GEO 세컨 홈페이지)** 서비스만 운영 중이다.
여기에 **블로그 바이럴마케팅**을 두 번째 사업 라인으로 추가한다.

- 대표(최중빈)는 성형외과 마케팅 15년 이상 경력 보유 → 의료광고법/의료법 리스크를 아는 사람이 하는 "정도(正道) 바이럴"로 차별화.
- 두 서비스는 **같은 고객(병원)한테 상호보완**이다: 홈페이지 = 검색에 잡히는 구조, 블로그 = 그 위에 얹는 콘텐츠 유입. 크로스셀 가능.

## 2. 서비스 포지셔닝 (핵심 원칙)

> **"순위를 조작하지 않습니다. 병원의 자산이 되는 블로그를 만듭니다."**

- **브랜드블로그 컨셉** — 경쟁 키워드 상위노출 사냥이 아니라, **자사명(병원명) + 관련 시술을 포괄하는 정직한 정보성 콘텐츠**를 장기적으로 축적해 "병원의 자산"을 만든다.
- **"키워드 잡고 상위노출" 컨셉은 버린다.** 작업글 냄새 = 역효과 + 의료법 리스크 + 순위 보장 압박을 유발하기 때문.
- **상위노출은 보장하지 않는다.** 순위는 쫓는 게 아니라 자산이 쌓이며 따라오는 결과.
- **발행 주기(과정)를 약속한다** — 주 2회 발행(월 8~9개). 결과(순위)가 아닌 과정을 약속하는 정직 프레임.
- **의료법 준수** 전면 강조: 치료경험담·대가성후기·전후사진·최상급표현·부작용없음 단정·뒷광고 전부 배제.

### 2-1. AI 사용에 대한 프레임 (중요)

- 콘텐츠는 **AI(Claude) + 의료 전문 기획·SEO 구조 설계·의료법 검수·원장 감수**로 제작한다.
- 따라서 **"AI를 쓴다"를 비방하는 카피는 절대 쓰지 않는다** (자기모순·거짓). 시장의 문제는 "AI를 썼다"가 아니라 **"의료 이해 없이, 검수 없이, 전략 없이 저품질로 양산했다"**이다.
- 공격 지점: ❌"AI로 썼다" → ✅"무검수 저품질 양산 / 의료 몰이해". 프레임 = **"같은 붓이라도 누가 그리느냐가 다르다"** (도구가 아니라 퀄리티가 차별점).
- 고객에게 AI 사용을 숨기지도, 앞세우지도 않는다. 파는 것은 기획·SEO 구조·의료법 검수·브랜드 전략.

## 3. 시장 가격 근거 (2026-08 WebSearch)

| 구간 | 월 비용 | 내용 |
|---|---|---|
| 초저가 | 20~30만 | AI 자동생성 약간 수정, 의료 이해 없음 → 저품질 판정 위험 (**우리의 적, 경쟁 안 함**) |
| 표준 | 50~100만 | 전문 SEO 적용, 꾸준한 발행 |
| 프리미엄 | 100~200만+ | 전략수립+블로그·플레이스 통합+경쟁사분석+주간리포트+전략미팅 |

- 포스팅 단가: 건당 평균 30만(숨고), 브랜드블로그 월 10건 = 66~77만. 성형외과 키워드 5개 경쟁 = 월 200~300만.
- **우리 가격 (사용자 확정)**: 월 **100~150만** 구독형, **주 2회 발행** 약속. 초저가와 경쟁하지 않고 정직한 프리미엄에 위치.
- 홈페이지 사업의 "GEO 액티브 운영(월 130만)" 티어와 가격대가 겹쳐 **묶음 판매(홈페이지+블로그)** 자연스러움.
- **표시 방식**: 정확한 금액은 "**진단 후 맞춤 견적**"(과·키워드 경쟁도마다 달라서 — 정직 브랜드에 부합). 숫자를 숨기는 게 아니라 "왜 딱 얼마라고 못 박지 않는지"를 정직하게 설명. "초저가는 안 한다" 원칙은 명시.

## 4. 플랫폼 전략 (정직하게 구분)

- **네이버 블로그** = 국내 네이버 검색용. 폐쇄형이라 디자인은 **이미지 단위 커스텀(타이틀/스킨/위젯)만** 가능 — 솔직하게 명시.
- **티스토리** = 구글 검색용 + **풀 커스텀 디자인 가능(HTML/CSS/JS = 우리 본업 기술)**. 최대 차별점.
- **아메바(ameblo, 일본)** = 기본 아님. **"일본 의료관광 환자 유입" 프리미엄 옵션**으로 분리(일본어 콘텐츠 = 실제 번역/검수 원가 존재).

## 5. 진입 구조 (C안 — 하이브리드)

루트 접속 시 두 서비스를 **명확히 갈래로 보여주되, 게이트로 막지 않는다.**

- 루트 `/index.html` 히어로 직후에 **두 개 카드 CTA 밴드(`.service-split`)** 신설:
  - 카드 1: **검색에 보이는 홈페이지** → 기존 홈페이지 제작 콘텐츠(`#portfolio` 등, 루트에 그대로 유지)
  - 카드 2: **자산이 되는 블로그 마케팅** → 신규 `/viral/`
- 헤더 nav(데스크톱/모바일)에 "블로그 마케팅" 추가, 푸터 `footer-tools`에 링크 추가.
- **기존 루트 콘텐츠·SEO는 건드리지 않는다** — 구글/네이버 서치콘솔 등록 + 콜드메일 링크가 전부 루트를 가리키고 홈페이지 키워드로 인덱싱돼 있어, 홈페이지 사업이 루트에 남고 바이럴이 서브페이지로 가는 비대칭은 **SEO 자산 보존을 위한 의도된 선택**.

## 6. 이번 세션 딜리버러블

1. **진입 구조 (C 하이브리드)**: 루트 `index.html` 두 카드 CTA + nav + 푸터 링크, `styles.css`에 `.service-split` 컴포넌트 추가.
2. **`/viral/index.html` 신규 서비스 랜딩** (`professional/index.html` 구조 계승, `styles.css` 공유):
   - 히어로 → 현실 진단 → 우리 방식 3박자(콘텐츠·디자인·진단) → 차별점(AI 프레임·주2회 약속·무보장 정직) → 플랫폼 전략 → 가격(진단 후 견적) → 증거 "준비 중"(정직) → FAQ(의료법·AI·보장·가격) → 상담 CTA.
   - JSON-LD `Service`, `noindex` 미적용(리드젠 페이지).
3. **`sitemap.xml`**에 `/viral/` 등록.
4. HTML 유효성 검사(Python html.parser) 통과.

### 스코프에서 제외 (다음 세션)

- **샘플글을 지금 지어내지 않는다.** 실제 블로그를 운영해야 진짜 샘플글이 나오므로, 가짜 샘플 제작은 정직 브랜드에 반한다.
- **꿈담 자체 티스토리 블로그** 실제 세팅 + 첫 글 작성 → 그 진짜 글들이 나중에 `/viral/` 랜딩의 레퍼런스로 역류해서 붙는 2단 로켓 구조.
- `/viral/`의 증거 섹션은 `professional/`이 쓴 방식대로 "실제 운영 사례 준비 중 / 자체 블로그 곧 공개"로 정직하게 처리.
- 티스토리 자체 블로그 개설 계정 = **꿈담 업무용 카카오 계정**으로(개인/로코코와 분리). 계정 정리 작업과 함께 다음 세션에서 진행.
