# 브랜드 이미지 에셋 (카드뉴스 · 네이버 블로그)

블로그 마케팅용 이미지를 만드는 **원본 소스**입니다.
각 파일은 그 자체가 이미지 1장이며, Claude Code의 `/design` 캔버스로 열어 PNG로 내보내 사용합니다.

## 왜 이런 방식인가

네이버 블로그는 HTML/CSS 커스텀이 불가능합니다.
바꿀 수 있는 건 **이미지 에셋 교체**뿐이라, 필요한 이미지를 코드로 만들어 PNG로 내보내는 방식을 씁니다.
캔바·미리캔버스 템플릿을 쓰지 않는 이유는 템플릿 티가 나면 "양산 안 한다"는 브랜드 메시지와 자기모순이기 때문입니다.

## 카드뉴스 색 규칙 (하이브리드 · 확정)

- **표지 · 마무리 CTA = A 미드나잇** (어두운 톤으로 양 끝을 잡아 주목도 확보)
- **본문 내용 카드 = B 라이트** (글이 많은 카드는 밝게 = 가독성)
- **핵심 전환 카드 1장만 = C 그라디언트** (포인트로 한 번만, 남발 금지)

### cardnews/ 구성 — 첫 글 "강남 성형외과 마케팅 15년" 편

| 파일 | 역할 | 톤 |
|---|---|---|
| `Main.dc.html` | ① 표지 | A 미드나잇 |
| `Card2.dc.html` | ② 문제 제기 | B 라이트 |
| `Card3.dc.html` | ③ 핵심 인사이트 | C 그라디언트 |
| `Card4.dc.html` | ④ 구조 3단계 | B 라이트 |
| `Card5.dc.html` | ⑤ 차별점 3가지 | B 라이트 |
| `Card6.dc.html` | ⑥ 마무리 CTA | A 미드나잇 |
| `OptionB` / `OptionC` | 색감 비교용 표지 시안 (미채택 보관) | — |

카드 규격은 **1080×1080** 정사각형(네이버 블로그 썸네일 표준)입니다.

## naver-blog/ 구성

블로그명 **"병원 마케팅 노트"**, 주소 `dream-ag`, 별명 `꿈담`.

| 파일 | 용도 | 규격 |
|---|---|---|
| `Main.dc.html` | 모바일앱 커버 이미지 | 1080×1440 |
| `TitleBanner.dc.html` | PC 타이틀(대문) 배너 | 966×300 |
| `CtaBanner.dc.html` | **본문 하단 반복 CTA 배너** (매 글 끝에 삽입) | 800×420 |
| `ProfileC.dc.html` | 블로그 프로필 이미지 — **채택** | 640×640 |
| `ProfileA` / `ProfileB` | 프로필 시안 (미채택 보관) | 640×640 |

`CtaBanner`가 인바운드 깔때기의 핵심입니다.
매 글 하단에 넣고 `https://dream-ag.co.kr/check` 로 링크를 겁니다.

## 카피 작성 규칙

본문 카피는 **마침표 뒤에서만 줄바꿈**합니다.
마침표 없는 제목·짧은 구는 억지로 쪼개지 않습니다.
긴 문장은 자연스러운 쉼표에서 한 번 끊는 것이 오히려 읽기 좋습니다.

## 주의

- PNG로 내보내면 웹폰트(Noto Sans KR)가 아니라 시스템 한글 폰트로 렌더될 수 있습니다. 업로드 전 실제 내보낸 이미지를 확인하세요.
- 실사 사진은 이 방식으로 만들 수 없습니다. 도식·일러스트·타이포만 해당하며, 사진이 필요하면 무료 스톡이나 외부 AI 생성 툴로 별도 조달합니다.
